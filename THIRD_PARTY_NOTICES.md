# Third-party browser assets

The application vendors these browser assets so its local interface remains usable offline:

- htmx 2.0.4, distributed under the Zero-Clause BSD License. The license text is stored at `src/arxiv_updater/static/vendor/HTMX-LICENSE.txt`.
- KaTeX 0.18.0 and its fonts, distributed under the MIT License. The license text is stored at `src/arxiv_updater/static/vendor/katex/KATEX-LICENSE.txt`.

The vendored files are unmodified release artifacts from the corresponding npm distributions.

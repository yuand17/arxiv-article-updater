# arXiv Updater v0.2.1

A release-readiness update for the packaged Windows and macOS applications.

Windows 与 macOS 封装版本的发布前可靠性更新。

## Fixes and safeguards / 修复与防护

- Updates Pillow to a version that resolves the known advisories found during the release audit, and updates the test runtime to its fixed major version.
- 将 Pillow 更新到已修复本次发布审计所发现已知安全公告的版本，并将测试运行时更新到已修复的新主版本。
- Prevents a fresh installation from creating a misleading empty pre-migration database backup.
- 避免全新安装首次启动时生成没有实际用户数据的“迁移前备份”。
- Reloads an existing macOS LaunchAgent when login startup is re-enabled, so a moved or replaced application does not leave launchd pointing to an older bundle.
- macOS 重新开启登录自启时会重载已有 LaunchAgent，避免应用移动或替换后 launchd 仍指向旧版本。
- Requires dependency, Windows packaged-app, and Apple Silicon packaged-app checks before `main` can be updated.
- 更新 `main` 前必须通过依赖审计、Windows 封装程序与 Apple Silicon 封装程序检查。
- Validates the release tag, Python package version, macOS bundle version, CPU architecture, empty first-run state, and absence of local databases/logs in release trees.
- 校验发布标签、Python 包版本、macOS Bundle 版本、CPU 架构、首次启动空状态，以及发布目录中不存在本地数据库或日志。
- Publishes `SHA256SUMS.txt`, refuses automatic overwrites of existing release assets, and includes the README and MIT License in each download.
- 发布 `SHA256SUMS.txt`、拒绝自动覆盖已有发布资产，并在每个下载包中包含 README 与 MIT License。

## Installation security notice / 安装安全说明

The Windows executable is not code-signed, and the macOS DMGs are ad-hoc signed but not notarized by Apple. Verify the downloaded ZIP or DMG against `SHA256SUMS.txt` before approving a SmartScreen or Gatekeeper warning. Move the macOS app to **Applications** before enabling login startup.

Windows 可执行文件尚未进行代码签名；macOS DMG 使用临时签名，但未经 Apple 公证。在允许 SmartScreen 或 Gatekeeper 安全警告前，请先用 `SHA256SUMS.txt` 核对 ZIP 或 DMG。开启 macOS 登录自启前，请先把应用移动到 **Applications（应用程序）**。

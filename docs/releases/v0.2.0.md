# arXiv Updater v0.2.0

The first packaged Windows and macOS release of the privacy-first local research-paper reader.

隐私优先本地论文阅读器的首个 Windows 与 macOS 双平台封装版本。

## Highlights / 版本亮点

- Adds downloadable Windows x64, Apple Silicon macOS, and Intel macOS applications with their Python runtime included.
- 新增包含完整 Python 运行环境的 Windows x64、Apple Silicon macOS 和 Intel macOS 下载版本。
- Adds a native macOS menu-bar lifecycle with single-instance control, graceful scheduler/server shutdown, and optional login startup.
- 新增 macOS 菜单栏生命周期、单实例控制、调度器与服务器完整退出，以及可选的登录自启。
- Stores packaged macOS databases, caches, browser profiles, backups, and logs under `~/Library/Application Support/arXiv Updater/`; optional API credentials use macOS Keychain.
- macOS 封装版的数据库、缓存、浏览器档案、备份与日志位于 `~/Library/Application Support/arXiv Updater/`；可选 API 凭据使用 macOS Keychain。
- Detects Google Chrome in standard Windows and macOS installation locations for explicit Cloudflare human verification.
- 可在 Windows 与 macOS 标准安装位置发现 Google Chrome，用于明确的 Cloudflare 人工验证。
- Adds GitHub Actions builds and packaged-service smoke tests before publishing release assets.
- 新增 GitHub Actions 构建与封装服务 smoke test，通过后才发布下载文件。

## Downloads and first launch / 下载与首次启动

Use the operating-system links in the repository [README](https://github.com/yuand17/arxiv-article-updater/blob/v0.2.0/README.md).

请使用仓库 [README](https://github.com/yuand17/arxiv-article-updater/blob/v0.2.0/README.md) 中对应操作系统的下载链接。

The macOS DMGs are ad-hoc signed but **not notarized by Apple**. On first launch, macOS may require the user to open **System Settings → Privacy & Security**, click **Open Anyway**, and confirm **Open**. Move the app to **Applications** before enabling login startup.

macOS DMG 使用临时签名，但**未经 Apple 公证**。首次启动时，用户可能需要打开 **系统设置 → 隐私与安全性**，点击 **仍要打开** 并确认 **打开**。开启登录自启前，请先把应用移动到 **Applications（应用程序）**。

## Privacy / 隐私

Release packages contain no API keys, personal interests, tracked authors, saved papers, reading history, paper database, logs, caches, or browser profiles.

发布包不包含 API key、个人兴趣、重点作者、收藏论文、阅读历史、论文数据库、日志、缓存或浏览器档案。

# arXiv Updater v0.1.0

The first public release of a privacy-first Windows research-paper reader.

隐私优先的 Windows 本地论文阅读器首个公开版本。

![arXiv Updater v0.1.0](https://raw.githubusercontent.com/yuand17/arxiv-article-updater/v0.1.0/docs/images/arxiv-updater-v0.1.0.jpg)

## Highlights / 版本亮点

- Builds a configurable three-day reading list from arXiv, SciRate, selected Google Scholar authors, and eight built-in journals.
- 使用 arXiv、SciRate、重点 Google Scholar 作者和 8 本内置期刊，生成篇数可配置的三日论文精选。
- Combines deterministic local BM25 ranking with optional DeepSeek reranking, while keeping a fully local fallback.
- 结合确定性的本地 BM25 排序与可选 DeepSeek 精排，并始终保留完全本地的回退路径。
- Stores the database, reading interactions, preferences, credentials, and Cloudflare verification profiles only on the user's computer.
- 数据库、阅读互动、偏好、凭据和 Cloudflare 验证档案均仅保存在用户自己的电脑上。
- Supports explicit human verification for SciRate, Science, and Science Advances without automating or bypassing Cloudflare.
- 支持 SciRate、Science 和 Science Advances 的明确人工验证，不自动化或绕过 Cloudflare。
- Includes a Windows tray lifecycle, local offline assets, SQLite migrations, automated tests, and cross-platform CI.
- 包含 Windows 托盘生命周期、本地离线资源、SQLite 迁移、自动化测试和跨平台 CI。

## Install / 安装

Requires Windows 10 or 11, 64-bit Python 3.12, and Git. Alternatively, download and extract **Source code (zip)** from the Assets section below.

需要 Windows 10 或 11、64 位 Python 3.12 和 Git。也可以从下方 Assets 下载并解压 **Source code (zip)**。

```powershell
git clone https://github.com/yuand17/arxiv-article-updater.git
Set-Location arxiv-article-updater
python -m venv .venv
.venv\Scripts\python.exe -m pip install -e .
Copy-Item .env.example .env
.venv\Scripts\arxiv-updater.exe init-db
powershell.exe -ExecutionPolicy Bypass -File scripts\install_windows_shortcuts.ps1
```

Use the desktop **arXiv Updater** shortcut after installation. Optional DeepSeek and SerpAPI credentials can be configured from the local Settings page.

安装后使用桌面的 **arXiv Updater** 快捷方式。可选的 DeepSeek 与 SerpAPI 凭据可在本机设置页中配置。

## Privacy / 隐私

A fresh clone contains no API keys, personal interests, tracked authors, saved papers, reading history, paper database, logs, or browser profiles.

全新 clone 不包含 API key、个人兴趣、重点作者、收藏论文、阅读历史、论文数据库、日志或浏览器档案。

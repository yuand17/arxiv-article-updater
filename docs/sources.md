# 来源、分类与调度

| 来源 | 默认节奏 | 行为 |
|---|---:|---|
| arXiv | 官方工作日发布 | 从上次成功边界回退一天，分页读取到时间边界；100 页只作为异常保护，不是日常论文总上限。 |
| SciRate | 3 天 | 读取 `range=3` 三日榜前 50，成功后清除离开榜单的旧热门标记。手动更新可打开专用 Chrome 完成人工验证。 |
| Google Scholar | 7 天 | 仅在设置页开启 SerpAPI 且已保存密钥时运行；普通作者主页链接只用于提取作者 ID，后台固定按发表时间同步每位作者最近 10 篇并去重。同步前通过免费的 SerpAPI Account API 读取账户真实月度剩余额度（单人免费计划为每月 250 次），缓存命中不再被本地误记为扣费请求；额度不足时不会静默只更新一部分作者。 |
| 用户期刊 | 1 天 | 逐本期刊增量同步，一本失败不会影响其他订阅或已有论文。 |
| 偏好画像 | 7 天且有新互动 | 仅在设置页开启 DeepSeek 且已保存密钥时运行；关闭或不可用时保留已有画像并继续本地推荐。 |
| 三天精选 | 3 天 | 所有到期来源先独立更新，再从严格三日窗口生成一个批次。 |
| 数据清理 | 每个成功三日批次后 | 删除超过 9 天且无互动、未被最近三个批次保护的论文。 |

## 期刊发现与筛选

新数据库没有默认期刊。用户只填写期刊名称和公开 HTTPS 官网；发现服务拒绝本机、私网、带凭据 URL、危险重定向和超大响应，并在同域名内执行最多两层、20 页的有限发现。程序读取 HTML、JSON-LD、ISSN、canonical 和 RSS/Atom 声明，使用出版社适配器和 Crossref 做交叉验证，然后实际解析端点并生成预览。

期刊条目按固定顺序处理：

1. 规范标题、作者、摘要、DOI、链接和日期并去重。
2. 优先使用出版社结构化类型，排除新闻、评论、社论、综述、勘误和撤稿等非原创内容。
3. PRL 原创 Letter 保留；普通来信只有得到原创研究证据才保留。
4. 物理专业期刊以期刊范围作为强证据；综合期刊必须从主题标签、标题或摘要获得明确物理证据。
5. 不确定的综合期刊条目默认排除，并在 `seen_source_items` 保存机器可读原因。

摘要只来自来源本身、已明确知道 ID 的 arXiv 元数据、出版社 citation meta，或本地 DOI/arXiv-ID 精确关联。无法可靠取得时显示“暂无摘要”。

## 三天精选

候选满足 `published_at` 或 `discovered_at` 位于最近三天，排除“不感兴趣”和最近 30 天内未实质更新的已推荐论文。本地 BM25 对标题使用 3 倍权重，结合近期性、重点作者、SciRate、期刊和来源多样性生成短名单：

```text
K = min(C, max(3 × N, 100), 300)
```

约 10% 短名单用于确定性探索。DeepSeek 按最多 50 篇分组精排，坏分组单独回退到本地分数。最终只保存设置中的前 `N` 篇；候选不足时不从第四天或更早论文补齐。
